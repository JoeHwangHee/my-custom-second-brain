# index.md — L1 인지유형 목록

L1 카테고리는 **인지유형 5종**이다(경량 유지). 새 인지유형 추가 시에만 수동 수정.
주제는 L1이 아니라 tags + 벡터가 담당한다(폴더는 인지유형당 flat).

조회 라우팅은 이 표가 아니라 벡터 검색(`tools/query.mjs`)이 수행한다. keywords는 저장 시 LLM의
인지유형 분류 가이드(화행 신호)이며 정본은 `_rules/categories/category_schema.md`다.

| 인지유형 | 경로 | 약어 | 핵심 질문 | 화행 신호 |
|---|---|---|---|---|
| 경험 | episodic/ | ep | 언제 무슨 일이 있었나 | 했다, 갔다, 오늘, 어제, 만났다, 봤다 |
| 개념 | semantic/ | se | 이것은 무엇인가 | 이다, 란, 개념, 정의, 의미, 원리 |
| 방법 | procedural/ | pr | 어떻게 하는가 | 하는 법, 먼저, 그다음, 절차, 방법, 단계 |
| 통찰 | reflective/ | rf | 여러 경험서 무엇을 알았나 | 되돌아보면, 깨달았다, 패턴, 교훈 |
| 주장 | thesis/ | th | 무엇을 주장하는가 | 해야 한다, 라고 본다, 입장, 당위, 평가 |
